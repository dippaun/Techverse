## 📖 About

TechVerse is a technology event management platform designed to simplify the registration and administration process for technical events, hackathons, robotics competitions, startup showcases, drone festivals, and other innovation-driven activities.

The platform provides separate interfaces for participants and administrators while maintaining a secure and scalable backend.

# ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/dippaun/Techverse.git
```

### Move into Project

```bash
cd Techverse
```

### Configure Database

1. Create a MySQL database.

2. Import

```
alter_students_table.sql
```

3. Update

```
config.php
```

with your database credentials.

---

# ▶️ Run Project

Place the project inside:

```
htdocs
```

for XAMPP or

```
www
```

for WAMP.

Then open

```
http://localhost/Techverse/
```
